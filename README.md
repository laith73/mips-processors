# MIPS Processors

This repository contains three implementations of the **MIPS ISA** developed in **VHDL** as part of the CprE 3810 Computer Architecture course at Iowa State University.

The project was completed collaboratively by **Laith Al Sairafi** and **Chase O'Connell** and explores the design and implementation of MIPS processor architectures, including single-cycle and pipelined designs.

## Features

* 32-bit MIPS processor implementations in VHDL
* Single-cycle and 5-stage pipelined architectures
* 32-bit ALU and processor control logic
* Instruction fetch and decode logic
* Pipeline registers
* Data forwarding and hazard detection
* Control hazard handling
* VHDL testbenches for component and processor verification
* MIPS assembly programs for functional testing

## Technologies

* **VHDL**
* **MIPS I Assembly**
* Digital logic and computer architecture concepts
